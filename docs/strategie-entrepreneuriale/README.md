# 🎯 Stratégie entrepreneuriale & Vision long terme — LAWOL

Ce dossier regroupe toute la réflexion managériale et entrepreneuriale sur le projet LAWOL : définition du problème, vision à long terme, plan de mise sur le marché, stratégie de croissance, modèles économiques.

## Contenu

| Fichier | Objet |
|---------|-------|
| `vision-long-terme.md` | Vision entrepreneuriale, problème résolu, north star, roadmap stratégique |
| `positionnement-marche.md` | Analyse concurrentielle, avantage compétitif, segmentation |
| `modele-economique.md` | Modèles de revenus, durabilité, prévisions financières |
| `plan-mise-marche.md` | Go-to-market, lancement, canaux d'acquisition |
| `croissance-agile.md` | Stratégie lean startup, itérations, pivots éventuels |
| `decision-log-lawol.md` | Décisions structurantes prises sur LAWOL (index) |
| `problems-found-lawol.md` | Problèmes identifiés et corrections appliquées (anti-répétition) |

## Règles d'usage

- **Un fichier = une réflexion bornée** : ne mélange pas stratégie et exécution technique.
- **Toute décision structurante** (stack, modèle économique, cible, pivot) doit être tracée dans `decision-log-lawol.md`.
- **Tout problème corrigé** (bug, écart de marché, fausse hypothèse) doit être tracé dans `problems-found-lawol.md`.
- Ce dossier est l'espace de discussion entre le fondateur et le régisseur pour la réflexion entrepreneuriale. La technique reste dans `docs/` (racine) et `apps/`.
