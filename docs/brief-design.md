# Brief — Design & Esthétique LAWOL.mr

## Objectif
Rendre le site LAWOL.mr **visuellement joli et élégant**. Utiliser le boilerplate HTML5 (localhost:8080) comme référence de qualité.

## Références
- **Boilerplate HTML5** : http://localhost:8080 (installer, moderne, responsive)
- **Site actuel** : https://lawol-mr.vercel.app
- **Style** : indigo, moderne, responsive, mobile-first

## Pages à améliorer

### 1. Landing page (/)
- Hero section attractive (gradient, image, CTA clair)
- Section "Comment ça marche" (3 étapes)
- Section "Pourquoi LAWOL.mr" (avantages)
- Section témoignages (fictifs pour l'instant)
- Footer complet

### 2. Page inscription (/inscription)
- Formulaire centré, carte attractive
- Icônes pour chaque Champ
- Validation visuelle (bordures vertes/rouges)
- Animation de soumission

### 3. Page profil (/profil/[telephone])
- En-tête avec avatar (initiales)
- Cartes d'offres avec ombres, hover effects
- Boutons d'action (postuler, partager, modifier)
- Filtres visuels

### 4. Page admin (/admin)
- Dashboard moderne avec graphiques (CSS pur)
- Tableaux stylés
- Navigation claire

## Critères de réussite
- Site responsive (mobile, tablette, desktop)
- Animations subtiles (hover, transition)
- Cohérence des couleurs (indigo + gray)
- Pas de régression fonctionnelle
- Build Vercel réussit

## Limites
- Ne pas toucher à la logique fonctionnelle
- Ne pas casser les fonctionnalités existantes
- Garder le style indigo + Tailwind
